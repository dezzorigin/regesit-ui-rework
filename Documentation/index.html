MODUL 02

Diagram Alur Sistem Vertikal

Visualisasi berorientasi vertikal (*mobile & compact screen friendly*) yang menggambarkan alur lengkap siklus data mulai dari pendaftaran peserta hingga pemindaian di pintu masuk venue.

Alur Registrasi Peserta → Penerbitan Tiket QR → Check-In Gate

Vertical Data Pipeline
1
Peserta Mengisi Form Pendaftaran (register.html)
Peserta memasukkan nama lengkap, email, WhatsApp, institusi, dan membubuhkan tanda tangan digital pada kanvas touch/mouse.
2
Client-Side Validation & Payload Dispatch
Script register.js memvalidasi regex email, format nomor HP, dan mengekspor tanda tangan menjadi data stream Base64 PNG. Mengirim POST /api/v1/events/{id}/register.
3
Back-End Memproses & Menyimpan Data
Menyimpan record attendee, generate nomor unik TIK-XXXX, upload tanda tangan ke S3, membuat Signed QR payload, dan mengembalikan HTTP 201 Created.
4
Front-End Merender E-Ticket & Ledakan Confetti
Halaman beralih ke #ticketSuccessView, merender QR Code resolusi tinggi, memicu animasi Confetti Cannon, dan mengizinkan download tiket gambar.
5
Hari-H Event: Panitia Memindai Tiket (scanner.html)
Kamera smartphone panitia mendeteksi QR → memanggil POST /api/v1/tickets/checkin → validasi status kehadiran dalam 3 detik → Web Audio synthesizer membunyikan nada sukses (A5-1760Hz).
6
Real-Time Sync ke Organizer Dashboard (dashboard.html)
Metrik kehadiran ter-update secara otomatis, grafik persentase gate bertambah, dan record log check-in tercatat di database.

Desain Token & Konvensi State CSS

Front-End menggunakan class CSS standar untuk menampilkan indikator feedback, animasi shake error, status pendaftaran, dan toast notification.

Matriks Class State Interaktif Front-End

Class Name CSS Target Elemen Perilaku Visual & Efek Trigger dari Response BE
.is-invalid / .input-error input, select, textarea Border berubah menjadi merah (#ef4444), background beraksen merah muda halus, dan outline kemerahan. Saat API mengembalikan status 400 / 422 dengan nama field yang tidak valid.
.shake-error .form-field-group, .signature-canvas-wrap Memicu animasi getar horizontal selama 0.35 detik untuk menarik perhatian mata pengguna. Dipasang bersamaan dengan .is-invalid saat validasi form gagal.
.card-success-pulse #highlightAttendeeBox (scanner) Memberikan efek border kilau hijau (#10b981) memudar selama 0.8s saat scan sukses. Saat endpoint check-in mengembalikan respon 200 OK (Tiket Valid).
.stamped #verifiedStampBadge (scanner) Memicu animasi cap stempel digital jatuh berputar (*stamp slam effect*) dengan rotasi -8deg. Dijalankan seketika saat tiket terkonfirmasi sah di pintu masuk.
.toast-card.success #toastContainer Muncul toast melayang sudut kanan atas berwarna hijau dengan progress bar auto-dismiss 3.5 detik. Aksi sukses (Buat event, Simpan setting, Export file, Download tiket).
.toast-card.warning #toastContainer Muncul toast melayang berwarna amber/oranye dengan ikon segitiga peringatan. Peringatan input form belum lengkap atau kuota hampir penuh.
.toast-card.danger #toastContainer Muncul toast melayang berwarna merah tua dengan ikon silang peringatan keras. Tiket sudah pernah check-in (409 Conflict) atau sistem offline.

Standar Kompatibilitas CSS & Gradient Text Rules

Untuk rendering teks bergradien (.hero-title-highlight) yang konsisten di semua mesin peramban (Gecko/Firefox, WebKit/Safari, dan Chromium/Blink), deklarasikan properti standar background-clip: text; berpasangan dengan vendor prefix -webkit-background-clip: text;:

CSS Code Standard 
.hero-title-highlight {
  background: linear-gradient(135deg, var(--color-primary) 0%, var(--color-secondary) 100%);
  -webkit-background-clip: text;
  background-clip: text; /* Wajib didefinisikan untuk kompatibilitas standar W3C */
  -webkit-text-fill-color: transparent;
  display: inline-block;
}

MODUL 06

Format Payload QR Code & Standar Keamanan

Spesifikasi payload string yang dienkode ke dalam 2D Barcode / QR Code untuk memastikan kompatibilitas pemindaian lintas perangkat kamera.

Format String Standar (Plain Pipe-Delimited)

QR Content Format 
TIK-8821|Budi Wicaksono|budi.wicaksono@goto.com|evt_tech_summit_2026

Rekomendasi Format Signed JWT Token (Anti-Pemalsuan)

Untuk event berbayar atau skala enterprise, disarankan menggunakan Compact Signed JWT dengan algoritma HMAC-SHA256 agar QR tidak bisa dipalsukan oleh pihak ketiga:

JWT QR Header & Payload Claims 
{
  "sub": "TIK-8821",
  "evt": "evt_tech_summit_2026",
  "cat": "VIP",
  "iat": 1787462400,
  "iss": "https://api.regesit.com"
}
MODUL 07

Logika Scanner, Audio Feedback & Offline-First Sync

Panduan arsitektur ketahanan sistem pemindaian di lapangan (scanner.html) untuk menangani kendala koneksi internet di venue dan audio synthesizer tanpa file eksternal.

1. Audio Chime Synthesis (Web Audio API)

Front-End membunyikan nada sinusoidal berfrekuensi 880Hz → 1760Hz menggunakan Web Audio API tanpa perlu me-load file MP3/WAV eksternal. Nada ini dipicu seketika respon 200 OK diterima dari backend.

2. Mekanisme Offline-First Resilience (IndexedDB Cache)

Ketika koneksi internet di venue terputus (navigator.onLine === false):

  • Daftar hash tiket yang sudah di-preload disimpan di IndexedDB browser panitia.
  • Pemindaian offline memvalidasi ke database lokal dan menyimpan log ke antrean offline_checkin_queue.
  • Saat koneksi internet kembali pulih, browser secara otomatis mengirimkan batch antrean ke endpoint POST /api/v1/tickets/batch-sync.
MODUL 08

Rekomendasi Skema Database (ERD)

Rancangan relasional tabel database (PostgreSQL / MySQL) yang selaras dengan seluruh entitas dan data model Front-End.

DDL Schema PostgreSQL / MySQL

SQL Schema DDL 
-- 1. Tabel Organizers / Akun Penyelenggara
CREATE TABLE organizers (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name VARCHAR(150) NOT NULL,
    email VARCHAR(150) UNIQUE NOT NULL,
    phone VARCHAR(30),
    subscription_tier VARCHAR(50) DEFAULT 'free', -- free, starter, standard, pro
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 2. Tabel Events
CREATE TABLE events (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    organizer_id UUID REFERENCES organizers(id) ON DELETE CASCADE,
    title VARCHAR(255) NOT NULL,
    slug VARCHAR(150) UNIQUE NOT NULL,
    format VARCHAR(30) DEFAULT 'offline', -- offline, webinar, hybrid
    venue_location TEXT NOT NULL,
    start_time TIMESTAMPTZ NOT NULL,
    end_time TIMESTAMPTZ NOT NULL,
    registration_deadline TIMESTAMPTZ NOT NULL,
    quota INT NOT NULL DEFAULT 100,
    terms_text TEXT,
    status VARCHAR(30) DEFAULT 'active', -- active, draft, completed
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 3. Tabel Dynamic Custom Questions
CREATE TABLE event_custom_fields (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    event_id UUID REFERENCES events(id) ON DELETE CASCADE,
    field_name VARCHAR(150) NOT NULL,
    field_type VARCHAR(30) NOT NULL, -- text, textarea, select, file, phone
    options_json JSONB,
    is_required BOOLEAN DEFAULT true,
    order_index INT DEFAULT 0
);

-- 4. Tabel Tickets & Attendees
CREATE TABLE attendees (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    event_id UUID REFERENCES events(id) ON DELETE CASCADE,
    ticket_code VARCHAR(30) UNIQUE NOT NULL, -- TIK-8821
    full_name VARCHAR(150) NOT NULL,
    email VARCHAR(150) NOT NULL,
    phone VARCHAR(30) NOT NULL,
    company VARCHAR(150),
    signature_url TEXT NOT NULL,
    is_checked_in BOOLEAN DEFAULT false,
    checked_in_at TIMESTAMPTZ,
    checked_in_gate VARCHAR(100),
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 5. Tabel Check-In Audit Logs
CREATE TABLE checkin_logs (
    id BIGSERIAL PRIMARY KEY,
    attendee_id UUID REFERENCES attendees(id) ON DELETE CASCADE,
    ticket_code VARCHAR(30) NOT NULL,
    scanned_by_user_id VARCHAR(100) NOT NULL,
    gate_name VARCHAR(100) NOT NULL,
    scanned_at TIMESTAMPTZ DEFAULT NOW(),
    status VARCHAR(30) NOT NULL -- SUCCESS, DUPLICATE_BLOCKED
);

HTTP Status Matrix & Toast Integration

Pedoman format respon error standar dari Back-End agar otomatis ditangkap dan dirender dengan mulus oleh sistem Toast Notification Front-End.

Status HTTP Arti Status Respon Front-End UI Toast Type
200 OK / 201 Created Permintaan berhasil diproses penuh. Menampilkan modal sukses, suara chime, ledakan confetti, atau update tabel. success
400 Bad Request Format JSON salah atau parameter hilang. Menyorot input error (.is-invalid) dan memicu shake animation. warning
401 Unauthorized Sesi login organizer telah kedaluwarsa. Redirect ke halaman login dengan pesan sesi habis. danger
404 Not Found Event atau tiket tidak ditemukan di database. Tampilan peringatan bahwa tiket palsu / salah event. danger
409 Conflict Tiket sudah pernah check-in sebelumnya. Menampilkan nama gate dan jam pertama kali check-in. danger
500 Server Error Kendala internal database / server crash. Pesan santun meminta peserta/panitia mencoba beberapa saat lagi. danger
