Regesit UI Rework · v1.1.0 · 2026-11-19

Diagram arsitektur & alur

Tiga diagram sistem ini digambar sebagai HTML+SVG statis — bukan Mermaid — supaya terbaca sama persis di repo, di Pages, maupun di print. Semua alur sudah diuji end-to-end (lihat e2e/smoke.spec.js).

01 / Arsitektur — situs statis tanpa backend

Browser memuat file langsung dari Cloudflare Pages. Satu-satunya state adalah localStorage. QR dibuat lokal oleh lib yang di-vendor; Google Fonts dan satu avatar Unsplash bersifat dekoratif.

02 / Alur peserta — daftar → tiket QR → check-in

Peserta mengisi form dan tanda tangan; tiket QR dibuat di browsernya sendiri. Di pintu masuk, panitia memindai (simulasi) dan tiket terverifikasi seketika.

03 / Alur organizer — buat event → tampil di dashboard

Dua jalur masuk yang sama-sama bermuara di satu store: wizard halaman penuh dan wizard modal di dashboard. Event tersimpan lokal dan dirender ulang setiap kali dashboard dimuat.
